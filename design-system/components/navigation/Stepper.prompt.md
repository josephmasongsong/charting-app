Large circular milestone stepper (Branch Planning goal tracking). See also `ProcessTimeline` for the compact numbered-dot version.

```jsx
<Stepper steps={[{label:"Description",icon:<PenLine/>,state:"done"},{label:"Stakeholders",state:"current"}]} />
```

Color code: done/complete green `#28A745`/`#16A660`, current/locked gold `#E9B949`, pending gray dashed connector.
