Clickable action button in five variants — use primary blue for in-flow actions and teal only for top-level entry CTAs.

```jsx
<Button>Next</Button>
<Button variant="outline">Previous</Button>
<Button variant="teal">View my Operational Review</Button>
<Button variant="destructive">Delete</Button>
<Button disabled>Continue</Button>
```

Variants: `primary` (default, action blue #0073CE), `outline` (white/blue border), `teal` (#006265, top-level CTAs only — never inside a form flow), `soft` (light blue #6FC7E8), `destructive` (#BA0F17). Radius 4px, padding 8px 18px, disabled state uses blue-100.
