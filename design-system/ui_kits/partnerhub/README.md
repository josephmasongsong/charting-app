# PartnerHub UI kit

Click-through recreation of BC Housing's internal PartnerHub extranet plus the public Feedback Forms flow, built from `bc-housing-design-system.jsx` (screenshots of the production .NET/Bootstrap apps).

Screens: **Dashboard** (sidebar shell, operational-review timeline, quick-start card, core-area progress, stat cards), **Feedback Wizard** (public multi-part form), **Staff Directory** (A–Z jump list + rows), **Profile** (photo, contact fields, assigned developments).

Composed entirely from `components/` primitives — no new visual patterns invented here.
