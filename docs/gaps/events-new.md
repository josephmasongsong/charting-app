# /events/new (+ /events/[id]/edit, /admin/events/[id]/edit) vs `log-event`

**Template:** `design-system/templates/log-event/LogEvent.dc.html` — "Log New Event" intake: blue `AppHeader`; four cards (Event details · Participation · Time and cost · Community partnership) each with a 30px `--action-selected` icon tile, 17px title and 13px muted subtitle; searchable combobox for site / activity type / partner; live participation total; quick-duration chips; a sticky bottom action bar ("N required fields left" · Cancel · Save disabled until complete); a sticky 320px "Required fields" checklist rail.
**App:** `src/components/EventForm.tsx` (client, 956 lines) rendered by `/events/new` (`mode="create"`), `/events/[id]/edit` and `/admin/events/[id]/edit` (`mode="edit"`, pre-filled from `initialData`). Options from `GET /api/events/options`; submit to `POST /api/events` (create), `PATCH /api/admin/events/[id]` (admin edit) or `PATCH /api/events/[id]`; server validation `createEventSchema` / `updateEventSchema` in `src/lib/validations/events.ts`. Form state is one `useState` object; validation is the hand-written `validateForm()` on submit plus server `details[]` mapped back to fields.
**Data sources:** `events` columns `title, event_date, description, event_duration, admin_duration, new_participants, returning_participants, event_is_youth_focused, has_co_host, community_partner_id, total_cost, activity_type_id, site_id` (+ `user_id` from the session); options tables `activity_types ⋈ program_goals`, `sites`, `community_partners`.

Behaviour to keep (all three routes): the `formData` shape and every `handleInputChange`/`handleCheckboxChange` call, `validateForm()` and its messages, the `apiData` payload (incl. `isFirstSaveAfterDuplication`), the URL/method branch on `mode`/`isAdmin`, the server-error mapping, the 1.5s success → `router.push('/events/[id]')`, `router.back()` on Cancel, the `Popover`+`Command` comboboxes (site search matches `name + address`), the `ui/calendar` picker, the "Loading..." options gate, and the `isDuplicated` / `!isAdmin` banners.

**Field map (every rendered template field has a column).** Title → `title`; Event date → `eventDate` (`event_date`); Site → `siteId`; Activity type → `activityTypeId`; youth checkbox → `eventIsYouthFocused`; Description → `description`; New/Returning → `newParticipants`/`returningParticipants`; Event duration → `eventDuration`; Admin time → `adminDuration`; Total cost → `totalCost` (string, `numeric(12,2)`); co-host checkbox → `hasCoHost`; Community partner → `communityPartnerId` (nullable). The template's Total tile is `new + returning`, derived on both sides.

**Raw palette in the file (64 occurrences; the "57" in `AUDIT.md` used a narrower colour list) by purpose**, and the token each group maps to: validation **29** — `text-red-600` ×12 messages, `border-red-500` ×11 invalid controls, `text-red-500` ×6 asterisks → `--danger` text, `--danger` border (or `aria-invalid:border-destructive` from `ui/input`); status banners **19** — blue `bg-blue-50 border-blue-200 text-blue-600/900/700` (duplicated), yellow `bg-yellow-50 border-yellow-200 text-yellow-600/900/700` (non-admin), green `bg-green-50 border-green-200 text-green-600/900/700` (success), red `bg-red-50 border-red-200 text-red-900/700` + a `text-red-600` icon counted above (error) → `Alert` variants `notice`/`warning`/success-treatment/`destructive` (no success variant exists; use the `--success` bar on `var(--bch-green-50,#EDF6EF)` as on `/reset-password/[token]`); live-total boxes **13** — `bg-blue-50 border-blue-200 text-blue-900 text-blue-700 + Badge bg-blue-600` (participants), `bg-purple-50 border-purple-200 text-purple-900 + bg-purple-600` (time), `bg-green-50 border-green-200 text-green-900 + bg-green-600` (cost per participant) → the template's single neutral tile (`--surface-muted`, `--border-default`); structural **3** — `border-gray-300` ×2 (raw checkboxes) → `ui/checkbox`; `border-blue-500` (partner indent) → the template's `--bch-gray-200` divider.

Strict reading: rendered elements first, then state the template's script declares but never binds.
